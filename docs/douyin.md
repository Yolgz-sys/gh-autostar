## 标题备选

1. 我用了三百多个开源项目，一个星都没点过
2. 写了个插件，把我欠开源作者的那些星补上了
3. 不白拿别人的东西，所以我把"点星"自动化了

> 三个里第一个最像人话，第二个有情绪，第三个有观点。抖音的完播率靠前三秒，
> 标题别用"推荐一个神器"这种，容易划走。

## 评论区置顶

```
项目开源地址：github.com/Yolgz-sys/gh-autostar
跨 agent 通用（Claude Code / Cursor / WorkBuddy 都行），MIT，随便用。
原理：只认克隆、装依赖、读源码这三种真实使用，判断全在本地，
同一仓库只点一次，一天最多 10 颗，全部记进 ledger.jsonl，可回溯可撤销。
```

> 原理那段最好也放到评论区。抖音里有人专门挑"是不是刷星工具"来质疑，
> 先把"每日上限 + 幂等 + 全量审计"摆出来，比在视频里解释更有说服力。

## 音频

- 配音：百度发音接口的「度丫丫」音色（`per=4`，年轻女声预设，非克隆），语速 5
- BGM：代码合成的 A 小调极简垫乐（72 BPM，无版权风险），比人声低约 20 dB
- 响度：人声段约 -16 dB，整体峰值 -0.8 dB，手机外放不用再调
