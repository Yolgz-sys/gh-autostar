## 分镜结构

| 段落 | 画面 | 字幕 |
|---|---|---|
| **开场钩子** | 星空底，大字三行 | 现在写代码，你还会自己去翻 GitHub 吗 |
| **把问题量化** | 金色数字 37 与灰色 0 对比 | 活干完了，用到的那些项目，主页你一眼都没看过 |
| **共情作者** | 贡献图，一年里只亮一格 | 可写代码的人，能收到的感谢，往往就只有这一颗星 |
| **打消疑虑** | 三张原则卡片 | 只认真实使用，一天最多十颗，每一颗都有记录 |
| **号召** | 金星 + 仓库名 | GitHub 搜 gh-autostar，一起把欠下的星，还给作者 |

> 这个顺序是对的：先戳中"我在白拿"，再让观众对作者产生亏欠感，
> 然后用三条原则消除"这是刷星工具吧"的顾虑，最后才给行动。

## 注意事项

- 视频无第三方平台水印，可直接发布
- 封面用结尾号召卡（信息最完整）；也可以换成「37 vs 0」那帧做对比封面，测一下哪个点击率高
- 如果平台判定"引导下载"，把链接只放评论区，口播不提
- 音轨是 96kHz 单声道 AAC，抖音上传后会自行转码；若某些安卓机播放异常，可先转成 44.1kHz 再传
